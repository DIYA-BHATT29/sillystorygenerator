# 🤣 Silly Story Generator

A hilarious web application that generates random funny stories to make you laugh out loud! Built with HTML, CSS, and JavaScript.


## ✨ Features

- **Three Humor Styles**: Choose from Silly & Absurd, Dark Humor, or Punny Jokes
- **Custom Names**: Personalize stories with your own funny character names
- **Animated Interface**: Floating emojis and smooth animations for extra fun
- **Responsive Design**: Works perfectly on desktop and mobile devices
- **Instant Generation**: Get a new hilarious story with one click
